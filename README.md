# SQL_DataWareHouse_Project

Building a modern data warehouse with Postgres SQL, including ETL process, data modelling and analytics.
This is a project which follows the medallion  architecture.

#### Specifications
- **Data Scources**: Import data from 2 sources(ERP and CRM) provided as a CSV file.
- **Data Quality**: Cleanse and resolve data quality issues before analysis.
- **Integration**: Combine both sources into a single, user-friendly data model designed for analytical query.
- **Scope**: Focus on the latest datasets only; historisation of data is not required.
- **Documentation**: Provided clear documentation of the data model to support both business stakeholders and analytics team.
